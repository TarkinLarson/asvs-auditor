## V3.5 Browser Origin Separation

| Requirement | Level | Text |
| :--- | :---: | :--- |
| **3.5.6** | L3 | Verify that JSONP functionality is not enabled anywhere across the application to avoid Cross-Site Script Inclusion (XSSI) attacks. |
| **3.5.7** | L3 | Verify that data requiring authorization is not included in script resource responses, like JavaScript files, to prevent Cross-Site Script Inclusion (XSSI) attacks. |
| **3.5.8** | L3 | Verify that authenticated resources (such as images, videos, scripts, and other documents) can be loaded or embedded on behalf of the user only when intended.
